## 1. 주제

**AI 에이전트로 푸는 청년의 일·생활 문제**

- 청년의 일과 생활 속 불편을 찾아 **AI 에이전트 기반 해결 서비스**를 기획·개발하는 실전형 대회
- 주제 안에서 해결할 문제는 자유롭게 정할 수 있음
- 주제 예시
  - 교육, 금융, 이동, 생활 편의 등 생활 속 문제 해결 서비스
  - 환경, 지역, 안전 등 사회문제 해결 서비스
  - 공공데이터 + 생성형 AI를 활용한 문제 해결 서비스
- 주관기관은 **데이터셋을 따로 제공하지 않음** (직접 확보)

## 8. 유의사항

### AI·외부 자원 활용

- 생성형 AI, 오픈소스, 템플릿, 외부 API·서비스 **자유롭게 활용 가능** — 단, 반드시 기재
  - 주요 내역 → 「AI 활용내역」
  - 상세 출처·링크·라이선스 → 소개서 별첨 「활용한 외부 자원·출처」 표
- 외부 데이터·이미지·음원·오픈소스·API 등 제3자 저작물은 **적법한 이용 권한 확보 + 출처·라이선스 표기**
- **실제 개인정보·민감정보를 외부 AI 서비스(API 포함)에 입력·전송 금지** (동의 여부와 무관). 필요 없으면 가상·샘플 데이터 사용
- 저작권·지식재산권은 참가자 귀속. 주관기관은 홍보 등 비영리 목적으로 결과물 일부 활용 가능

### 기존 작업물 재사용 제한

- 기존 프로젝트를 **실질적 변경 없이** 제출 불가
- **다른 공모전·대회에 출품했거나 수상한 결과물과 동일·실질적으로 유사한 결과물 제출 불가**
  - 수정·고도화한 경우, 미수상·출품 철회 이력이 있는 경우도 포함
  - → 이전 프로젝트(예: 다른 대회 출품작)를 재활용하려면 이 조항에 걸리는지 반드시 확인

### 마감 후 변경 제한

- 마감 후 신규 제출·평가 내용 변경 불가
- 본선 준비 기간에 허용되는 것: **접속 복구, 인증정보 교체, 실행 환경 복구**만
- 기능·알고리즘·프롬프트·데이터 변경은 **불허** → 제출 시점에 완성도를 최대한 끌어올릴 것
- 배포한 프로토타입(서버, API 키 만료 등)이 **심사 기간(~11/30)과 본선(12/7)까지 계속 동작**하도록 관리

### 제재

- 허위 기재·은폐, 표절, 도용, 금지된 타 대회 출품·수상작 제출 → 심사 제외, 수상 후 확인 시 수상 취소 + 상금·상장 반환
- 저작권·라이선스·개인정보 침해 → 중대성에 따라 보완 요청 ~ 수상 취소
- 중대한 경우 향후 3년간 대한상의 주관 행사 참가 제한 가능
